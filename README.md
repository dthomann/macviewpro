# MacViewPro

**Release repository** for [MacViewPro](https://www.macviewpro.com) — a free native macOS image viewer inspired by IrfanView.

**Freeware, closed source.** This repo ships release notes, licenses, and installer downloads only. There is no application source code here.

Website: [macviewpro.com](https://www.macviewpro.com)

## Features

- Fast folder navigation (Space / Backspace); neighbours are prefetched; no import library
- Twelve window fit modes and seven fullscreen modes; exact 100% zoom; pixel grid above 800%
- IrfanView-style keyboard shortcuts (rebindable)
- Local editing: rotate, flip, crop, resize, brightness/contrast, curves, sharpen, blur, and more
- EXIF / IPTC / XMP inspector; animated GIF; multipage TIFF and PDF
- Optional in-app updates (Sparkle); no account, no telemetry

## Supported formats

**Read:** JPEG, PNG, TIFF, GIF, HEIC/HEIF, WebP, AVIF, BMP, ICO, PSD, PDF, and major camera RAW (Canon, Nikon, Sony, Adobe DNG, Olympus, Fujifilm, Panasonic, Pentax, Samsung via system imaging).

**Write (Save As):** JPEG, PNG, TIFF, GIF, HEIC, WebP, BMP (with per-format options).

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon or Intel Mac
- Universal binary (~15 MB)

## Install

1. Download the latest **MacViewPro-*.dmg** from [Releases](https://github.com/dthomann/macviewpro/releases), or get the stable installer from [macviewpro.com](https://www.macviewpro.com/downloads/MacViewPro.dmg).
2. Open the DMG and drag **MacViewPro** to Applications.
3. Launch from Applications (Gatekeeper / notarized build).
